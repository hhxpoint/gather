# ADR 0010：窗口与工作区的跨重启会话连续

- 状态：Accepted
- 日期：2026-11-23
- 范围：`apps/desktop`

## 背景

Gather 之前每次启动都是 1200×820 的默认窗口和示例文稿，即使用户刚刚在同一块屏幕上编辑过某个工作区。对日常写作工具来说，“继续上次写的地方”比多一个按钮更重要，但恢复路径不能绕过已有的目录边界、恢复快照和冲突检测。

窗口位置也不能盲目写入：显示器可能被拔掉、分辨率改变或窗口大部分在屏幕外。恢复时必须把窗口放回可见工作区，否则用户会看到“应用启动了但没有窗口”。

## 决策

1. **两个独立、带版本的 JSON 文件。** `window-state.json` 与 `workspace-session.json` 都放在 `app.getPath('userData')`；损坏一个不影响另一个。
2. **原子写。** 异步保存使用现有的临时文件 + `fsync` + rename；窗口关闭时用同步原子写，避免应用退出时丢失最后一次尺寸。
3. **窗口状态只恢复几何与最大化。** 保存普通状态 bounds（`getNormalBounds`）和 `maximized`；启动时按当前显示器 `workArea` 归一化：
   - 优先选择与保存矩形重叠面积最大的显示器；
   - 重叠过小或没有显示器时，在主显示器居中；
   - 宽高不低于 760×520，且不超过所在工作区；
   - 最大化在 `ready-to-show` 时恢复，普通 bounds 继续保留供还原。
4. **工作区会话只保存根与相对路径。** `{ root, relativePath }`；不保存文稿内容、搜索词、滚动位置或未保存数据。最后文稿路径只在与 `listWorkspace` 的文件表匹配时使用，渲染层不能提交绝对路径。
5. **恢复先验证目录。** 启动时读取会话，重新 `listWorkspace(root)`；文件不存在则只恢复工作区并把会话中的文件置空；根目录不存在（ENOENT/ENOTDIR）才清除会话；权限等暂时错误保留记录，下次启动重试。
6. **启动自动恢复，但尊重用户操作。** 渲染层通过共享 Promise 只发起一次恢复（兼容 React StrictMode）；如果恢复途中用户已打开工作区/文件，则忽略迟到结果。恢复文稿仍走 `workspace:openFile`，因此目录边界、文件版本与 watcher 全部生效。
7. **关闭工作区就是清除会话。** 用户显式关闭文件夹后，下次启动不再偷偷恢复；窗口尺寸与位置仍保留。文件打开、工作区切换、Save As 和单文件打开都会更新或清除会话。
8. **与恢复快照共存。** 启动恢复文稿后，如果该文稿有未保存快照，恢复横幅继续显示；用户主动恢复后才变成脏文稿。不把会话恢复当成自动保存。

## 被否方案

- **localStorage 保存工作区/窗口状态。** 与文稿状态分散在两个存储，清理浏览器数据会丢；主进程也无法在窗口关闭同步落盘。
- **一个 session 文件装所有状态。** 一个损坏或版本不兼容会同时丢窗口和工作区；分开更容易容错。
- **保存绝对文件路径并直接打开。** 绕过工作区文件表与目录边界；也不利于处理文件被移动/删除。
- **不校验显示器直接套用 x/y。** 拔掉外接屏后窗口会落到看不见的位置。
- **恢复时自动覆盖磁盘。** 会话只恢复“打开什么”，不恢复“内容”；未保存内容仍由恢复快照机制处理。
- **记住最近 5 个工作区并弹出选择框。** 首版先做可预测的单一会话；最近列表需要额外 UI 与清理语义。

## 后果与边界

- 已验证（Windows staging）：
  - 窗口从默认 1200×820 调整到 120,80,1000×700 后关闭，重启恢复到相同位置/尺寸；
  - 最大化后重启，窗口恢复为最大化，普通 bounds 仍为 1000×700；
  - 工作区与 `nested/笔记.md` 重启后自动打开，状态为“已恢复上次工作区与文稿”；
  - 删除最后文稿后重启，只恢复工作区，示例文稿保留并提示“上次文稿已不在文件夹”；
  - 重命名根目录后重启，示例文稿保留，提示“上次工作区已不存在，记录已清除”；
  - 关闭工作区后重启，不恢复工作区；窗口尺寸仍恢复；
  - 强杀后重启，工作区/文稿恢复且恢复快照横幅出现，点击“恢复”得到未保存内容。
- 单元测试覆盖窗口矩形归一化、窗口/工作区存储 round-trip、同步写、损坏/版本不兼容与非法相对路径。
- 未验证：多显示器拔插的真实矩阵、Linux（X11/Wayland）窗口恢复、macOS、DPI 缩放切换。窗口状态文件只含几何信息；工作区会话只含路径，不含文稿内容，但仍是本机 userData 数据。
- 未实现：最近工作区列表、单文件（无工作区）会话、滚动位置/光标恢复、每工作区独立搜索历史。

## 复现

```bash
npm run stage -w @gather/desktop
# 打开工作区与嵌套文稿，调整窗口大小/位置，关闭并重启
# 可选：最大化窗口，关闭并重启
# 删除最后文稿或重命名根目录，重启观察降级提示
# 强杀后重启，确认恢复快照横幅仍出现
```
