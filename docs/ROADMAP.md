# Gather Roadmap

这份路线图描述**已交付范围与后续验收门槛**，不是发布日期承诺。当前公开版本是 [`v0.1.0`](https://github.com/hhxpoint/gather/releases/tag/v0.1.0)。

## 当前版本：0.1.0

Gather 0.1.0 已交付：

- Windows 10/11 x64：NSIS 安装版、便携版；
- Linux x86_64：AppImage、deb；
- 项目站下载区、`SHA256SUMS.txt`、[下载后怎么用](QUICKSTART.md)；
- Markdown 源文件编辑、文件夹工作区、单文件查找/替换、跨文稿搜索；
- GFM 表格/本地图片预览、安全外链；
- 专注模式、阅读模式、阅读目录/查找/代码高亮；
- CRLF/BOM 保真、原子写入、冲突拒绝、崩溃恢复快照、外部变更提示；
- 窗口、工作区与最后文稿恢复；
- A4 PDF 与含本地图片 HTML 导出；
- Windows/Ubuntu CI、双平台安装包构建与 Release 校验和。

当前边界：

- 安装包未签名，Windows 可能触发 SmartScreen；
- 没有自动更新、升级/回滚或干净 VM 安装矩阵；
- Linux 图形会话、IME、字体回退与 200% 缩放尚未实测；
- Release 大文件尚未在本机重新下载安装，只完成 API digest 与 `SHA256SUMS.txt` 交叉核对；
- 仍缺阅读标注、精确段落/字符同步、打印专用版式、全应用暗色主题、工作区树形文件操作、跨文稿替换、AI/RAG 与 DOCX。

## 质量门槛

### 数据安全

- 强制杀进程、断电模拟、磁盘满、只读目录、并发保存后，原文可恢复；
- 冲突只能整体载入或另存，不能静默覆盖；
- 恢复快照有明确保留/清理策略，未加密边界写清；
- 真实 Windows/Linux 文件系统各跑一轮，不只依赖注入测试。

### 字节保真

- LF、CRLF、BOM、无结尾换行 round-trip；
- frontmatter、表格、HTML 块、CJK、emoji、超长行纳入 golden corpus；
- 混合行尾的归一策略显式提示，不悄悄改写。

### 编辑与输入

- Windows 微软拼音/搜狗、Linux Fcitx5/IBus 在 X11/Wayland 下无丢字、无重复、候选框定位正确；
- 5 MiB/10 万字符文稿打开、滚动、搜索与输入延迟有基线；
- 200% 缩放、全键盘操作、屏幕阅读器可读；
- 打印专用版式与阅读标注进入验收。

### 分发

- Windows Authenticode 签名与 Linux GPG/仓库签名方案落地；
- 自动更新、升级、回滚与干净 VM 安装/卸载可演练；
- Release 资产继续提供 SHA-256、来源与未签名/签名状态；
- Windows 10/11、Ubuntu 22.04/24.04、Fedora 当前稳定版完成矩阵。

### 隐私与 AI

- AI 默认关闭、默认不上传；
- 本地模型优先，BYOK 不内置付费密钥；
- 模型提案必须逐块审阅，拒绝即不落盘；
- 崩溃/错误上报默认关闭或明确同意，且不含文稿内容。

## 非目标

- 云端协作 SaaS、账号体系、多人实时协同；
- Notion 式块数据库或私有文档格式；
- 默认“上传文档给模型”；
- 用“AI 自动写完”替代作者审阅；
- 在质量门槛未通过时宣称稳定版或工业级签名分发。

## 团队与时间

0.1.0 由单人维护完成，后续版本取决于真实测试与反馈。两人以上可以并行桌面、AI、站点与 QA，但 IME、Linux 矩阵、签名与数据安全测试不能按人数线性压缩。路线图中的量级是范围估算，不是发布日期。
